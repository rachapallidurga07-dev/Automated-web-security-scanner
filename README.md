# Automated Web Security Scanner

## Project Overview
Automated Web Security Scanner is a Python-based
cybersecurity application designed to analyze website
security configurations and identify potential weaknesses.

## Technologies Used
- Python
- Tkinter
- Requests
- VS Code

## Features
1. HTTPS Security Checking
2. HTTP Security Header Analysis
3. Basic CORS Configuration Checking
4. Cookie Security Checking
5. Security Configuration Score
6. Risk Assessment
7. Downloadable Security Report
8. Graphical User Interface

## System Requirements
- Windows 10 or 11
- Python 3.10 or above
- VS Code or another Python editor
- Internet Connection

## Installation

Step 1: Download the project.

Step 2: Open the project folder in VS Code.

Step 3: Install the required library:

    py -m pip install -r requirements.txt

Step 4: Run the application:

    py web_scanner.py

## How to Use
1. Open the application.
2. Enter a website URL.
3. Click SCAN WEBSITE.
4. View the security configuration results.
5. Click DOWNLOAD REPORT.
6. Save the report as a text file.

Only scan websites you own or are authorized to assess.

## Project Objective
To develop a Python-based cybersecurity tool that
automatically checks common website security
configurations and generates an understandable report.

## Limitations
- This is a basic configuration scanner.
- It does not perform penetration testing.
- Missing security headers do not always indicate vulnerabilities.
- The security score is an illustrative configuration score.

## Conclusion
The Automated Web Security Scanner demonstrates
how Python can be used to inspect website security
configurations and generate security reports.
